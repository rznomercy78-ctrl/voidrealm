FAQ

Perguntas frequentes

Qual versão do Minecraft é compatível?

Esta versão do site está configurada para Minecraft Java 1.21.1 com Fabric.

O mod é gratuito?

Sim. O botão de download pode ser conectado ao arquivo ou pacote oficial do seu projeto.

As masmorras são sempre iguais?

A ideia do projeto é usar geração variada para que diferentes explorações tragam layouts e encontros diferentes.

Posso jogar multiplayer?

Isso depende da implementação do mod e da configuração do servidor. Confira os requisitos da versão que você distribuir.

Como reportar bugs?

Use o seu servidor Discord ou canal de suporte para receber sugestões e relatos da comunidade.
